# Reference 03 — TikTok Ads

Script completi per TikTok ads (organic-looking / UGC style). Il copy
TikTok deve sembrare contenuto, non pubblicità. Imperfezione voluta.

---

## 1. OUTPUT OBBLIGATORIO per ogni TikTok ad

Consegna sempre tutti e 7 i blocchi sotto. Nessuno è opzionale.

### Blocco 1 — HOOK (0–3 sec)
**3 varianti** obbligatorie:
- Variante sicura
- Variante contrarian
- Variante shock/pattern-interrupt

### Blocco 2 — SCRIPT COMPLETO
**3 durate** obbligatorie: 15s, 30s, 45s.

Formato timestamp OBBLIGATORIO:
```
[0-3s]   HOOK
[3-7s]   PROBLEMA / CURIOSITÀ AMPLIFICATA
[7-15s]  SOLUZIONE + DIMOSTRAZIONE
[15-25s] PROOF (review, numeri, UGC style)
[25-30s] CTA + URGENZA
```

Per ogni riga indica:
- Voice-over (VO) testuale
- Visual/azione on-camera
- Testo on-screen (se diverso dal VO)

### Blocco 3 — CAPTION (sotto video)
**2 varianti**:
- Hook-driven (ripete/amplifica il hook del video)
- Storytelling (short story che prolunga l'engagement)

Lunghezza: 80–150 caratteri. Mai più di 3 righe visibili senza "more".

### Blocco 4 — HASHTAG STRATEGY
Esattamente **7 hashtag**: 3 broad + 3 niche + 1 branded.
Esempio prodotto pet:
- Broad: #petlovers #doglife #petsoftiktok
- Niche: #dogearcleaning #puppygrooming #reactivedogs
- Branded: #[brandname]

### Blocco 5 — VOICE-OVER NOTES
Indica per ogni segmento:
- Tono (energico / sussurrato / confessionale / urgente / pacato)
- Pause (dove rallentare, dove accelerare)
- Emphasis (quali parole enfatizzare)
- Accent / stile (cordiale, amico, esperto, best-friend)

### Blocco 6 — B-ROLL SUGGESTIONS
Frame-by-frame cosa mostrare. Ogni secondo deve avere un'azione.
Formato:
```
[0-2s] Close-up mani che tengono il prodotto, luce naturale finestra
[2-4s] Zoom sul problema visibile (es. unghia rotta del cane)
[4-7s] Demo 3-step del prodotto in uso, sfondo cucina casalinga
...
```

### Blocco 7 — TESTO ON-SCREEN
Tutte le scritte che devono apparire sul video, con timestamp e
posizione. Formato:
```
[0-3s] TOP CENTER: "Perché il tuo cane ti morde durante il taglio"
[3-6s] BOTTOM: "(non è cattivo, è in dolore)"
[6-9s] BOTTOM: "Ho trovato UNA soluzione ↓"
...
```

## 2. STILE TIKTOK — REGOLE NON NEGOZIABILI

1. **Native-looking**. Mai "ads-y". Niente musica stock orchestrale,
   niente pack-shot studio, niente voce professionale doppiata.
2. **UGC vibes**. Foto verticale, luce naturale, telefono in mano,
   audio da telefono.
3. **Imperfezione voluta**. Un "ehm", un sorriso spontaneo, un
   errore di inquadratura nei primi 3 secondi = hook rate +15%.
4. **Hook come reazione**. I migliori hook TikTok sembrano reazioni
   genuine a qualcosa che è appena successo.
5. **Mai "Hey guys"**. Mai "Oggi vi voglio parlare di...". Mai
   "Quindi allora...".
6. **On-screen text sempre**. TikTok vede l'80% dei video senza
   audio. Il testo on-screen DEVE veicolare il messaggio anche
   mutato.

## 3. STRUTTURE PROVATE (scegli una per script)

### Struttura A — Problem / Agitation / Solution (PAS)
Best per: health, beauty, pet, baby
```
[0-3s] Hook: problema specifico
[3-10s] Agitation: "se non lo risolvi, succede X"
[10-20s] Solution: prodotto in azione + mechanism
[20-28s] Proof: review/numeri/demo
[28-30s] CTA: "link in bio" + urgency
```

### Struttura B — Before / After / Bridge (BAB)
Best per: fitness, skincare, home transformation
```
[0-3s] Hook: "ho cambiato X in Y giorni"
[3-8s] Before: come stavo/ero prima
[8-15s] Bridge: cosa ho fatto (prodotto)
[15-25s] After: risultati specifici
[25-30s] CTA + link
```

### Struttura C — Story Time (native TikTok)
Best per: fashion, gadget, lifestyle
```
[0-3s] Hook: "Non avrei mai pensato di comprare [X] ma..."
[3-10s] Setup della storia
[10-20s] Turning point + prodotto
[20-28s] Outcome + proof
[28-30s] CTA soft
```

### Struttura D — Listicle / Top X
Best per: gadget, home, tech accessories
```
[0-3s] Hook: "3 motivi per cui [target] sta sbagliando [X]"
[3-10s] Motivo 1 con mini demo
[10-17s] Motivo 2
[17-24s] Motivo 3 + soluzione (prodotto)
[24-30s] CTA
```

## 4. CTA TIKTOK — FORMULE VINCENTI

- "Link in bio, sparisce alle 23:59"
- "Seriamente testalo, ti ringrazierò dopo"
- "Cercalo come [brand] su Amazon/Google"
- "Check out the link if you wanna try it"
- "Commenta 'ME' e ti mando il link"

**Mai**: "Acquistalo ora!", "Compra subito!", "Offerta limitata!!!"

---

## 5. CAPTION FORMULAS

### Hook-driven caption
```
[ripetizione hook] [elaborazione in 1 riga] [emoji contestuale]

[CTA soft + link]
```
Esempio: "Perché il tuo cane urla durante il taglio delle unghie
(non è cattivo). Ecco cosa usiamo noi 🐾 Link nella bio."

### Storytelling caption
```
[apertura con dettaglio concreto] [conflict/problem] [turning point] [CTA]
```
Esempio: "Il mio golden ha preso a morderci ogni volta che prendevamo
le forbicine. Pensavamo fosse cattiveria. Poi il veterinario ci ha
detto che era dolore. Ora usiamo questo e niente più morsi 👇"

## 7. SELF-CHECK TIKTOK

Prima di consegnare, verifica:

- [ ] Hook entro 3 secondi?
- [ ] Il video funziona anche senza audio (testo on-screen)?
- [ ] Ogni secondo ha un'azione visual?
- [ ] Il CTA non suona ads-y?
- [ ] Il script è dicibile ad alta voce in modo naturale?
- [ ] Sembra un TikTok organico, non un ad?
- [ ] Lingua corretta?

Se NO a una sola → riscrivi.
